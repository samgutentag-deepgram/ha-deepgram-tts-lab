9. Where the work happens

Three folders, three branches, one repo. All three sit under ~/Developer for a boring but important reason: that is the only place git signs your commits as you personally. Anywhere else and this personal repo gets work-account commits.

10. Why the repo does not move to the lab

The code and the story about the code are two different things, so they live in two different places. The code is a public fork on your personal account, and it stays where personal commits get signed correctly. When there is something worth writing up, a campaign repo at ~/LABS/flux-tts-home-assistant-lab reads this one without containing it.
